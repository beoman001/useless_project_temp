# BALDNESS FINDER™ 🎯

## Basic Details

### Team Name: solo 

### Team Members

### Project Description

BALDNESS FINDER™ is an entertainment-only computer vision web application that analyzes photographs or camera input to investigate visible hairline and hair coverage. It detects faces, evaluates visible evidence, calculates a BALDNESS INDEX™, and provides a dramatically serious verdict for a completely unnecessary problem.

### The Problem (that doesn't exist)

People have been asking the most important question nobody actually needs answered: "Am I going bald?" Mirrors, selfies, friends, and random opinions have failed to provide a sufficiently dramatic scientific investigation.

### The Solution (that nobody asked for)

BALDNESS FINDER™ uses browser-based computer vision to analyze a person's visible hairline and forehead area. It provides a BALDNESS INDEX™, classification, confidence level, evidence summary, unnecessary roast, and dramatic BALDNESS EMERGENCY™ alerts when appropriate.
